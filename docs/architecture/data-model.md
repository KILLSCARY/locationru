# Модель данных

Первоначальная модель данных Resilient Taxi хранится в PostgreSQL и управляется
через Prisma. Геопространственное расширение PostGIS включается отдельным
инициализационным SQL-скриптом инфраструктуры.

## Сущности и связи

### User

Основная учётная запись. Телефон уникален и хранится только в нормализованном
формате E.164, например `+79990000000`. На уровне базы действует ограничение:
знак `+`, ненулевой код страны и от 8 до 15 цифр.

У пользователя может быть не более одного `PassengerProfile`, не более одного
`DriverProfile` и несколько `DeviceSession`.

### PassengerProfile

Профиль пассажира связан с `User` отношением один-к-одному. `userId` одновременно
является primary key и foreign key. Рейтинг ограничен диапазоном от 0 до 5,
счётчик завершённых поездок не может быть отрицательным.

### DriverProfile

Профиль водителя связан с `User` отношением один-к-одному и содержит рабочий
статус, статус проверки, рейтинг и комиссию. Комиссия хранится в basis points:
`100` означает 1%, `10000` — 100%. Допустимый диапазон — от 0 до 10000.

Один водитель может иметь несколько автомобилей.

### Vehicle

Автомобиль принадлежит одному `DriverProfile`. Регистрационный номер уникален;
перед записью приложение должно нормализовать его до верхнего регистра без
лишних пробелов.

### DeviceSession

Сессия устройства принадлежит пользователю. Пара `userId + deviceId` уникальна.
В базе хранится только криптографический хеш refresh token в
`refreshTokenHash` — исходный refresh token сохранять запрещено.

## Удаление

Профили, автомобили и сессии удаляются каскадно вместе с соответствующим
пользователем. Удаление профиля водителя каскадно удаляет его автомобили.

## Индексы

Индексы покрывают основные будущие сценарии:

- поиск пользователей по роли и статусу;
- сортировку пользователей по времени создания;
- подбор водителей по рабочему статусу и статусу проверки;
- сортировку водителей по рейтингу;
- поиск автомобилей водителя по статусу;
- поиск активных или отозванных сессий пользователя;
- обслуживание устаревших сессий по `lastSeenAt`.

## Development seed

`pnpm --filter @resilient-taxi/api db:seed` создаёт или обновляет одного
администратора с телефоном из `SEED_ADMIN_PHONE`. Seed выполняется только при
`NODE_ENV=development`; в остальных окружениях он завершается без изменений.

## Поездки

Таблицы `trips`, `trip_stops` и `trip_status_history` описаны в
[домене поездки](trip-domain.md). Геоданные используют PostGIS geography Point
в SRID 4326, а история статусов неизменно фиксирует автора и причину перехода.
